# 0.1.0 验证记录

日期：2026-10-23。版本来源：DSH npm 发布包 `0.2.1-rc.2`，不是自建仿真聊天页面。

## 已完成

- JavaScript 语法检查和客户端构建通过。
- 58 项单元与边界测试通过，覆盖上下文裁剪、密钥形状遮蔽、当前会话模型路由、最低思考档位选择、完整结束状态、并发合并、取消、超时、草稿版本校验、会话切换、设置持久化与冲突，以及 token 统计。
- 72 个离线回放用例通过，检查上下文构造和输出规则。它们使用预先编写的候选，不调用模型，因此不衡量预测命中率。
- 在 Linux / Chromium 的真实 DSH Web UI 中，12 项浏览器交互断言通过：原生 ModuleLoader 加载、显示层不污染草稿、Shift+Tab、输入法组词、Tab 整句采纳、不自动发送、一次撤销、Esc 忽略、自行输入优先、原生设置页、保存即时生效、关闭后停止预测请求。
- 浏览器验证无 JavaScript 页面异常。DSH 自身的 VS Code 图标端点返回过 404，不影响本插件功能。

机器可读记录在 `browser-results.json` 与 `replay-results.json`。浏览器测试响应由本地 `FixtureAdapter` 生成；其 180 毫秒等待仅是测试延迟，不是真实服务商测速。

## 尚未验证

- Windows/macOS 原生桌面壳的实机安装与操作。代码通过 DSH 原生 Connection RPC 和输入接口工作，但不能把 Web 验证等同于 Windows 桌面实测。
- DSH 0.2.1-rc.1 的运行验证；0.2.1-rc.2 是本次实际测试版本。
- 使用真实 DeepSeek 或其他模型的预测命中率、接受率、费用和网络延迟。本次没有使用用户 API Key 或订阅额度。

## 结果解释

该版本验证了插件工程链路与确定性边界，未证明预测质量等同 Codex。首次实际使用可先保持默认模型来源，若响应慢，在“下一句预测”设置中单独选择已配置的快速模型，或增加等待上限。

## 复现

基础检查：源码根目录运行 `npm run check`。真实浏览器测试：参阅 `qa/README.md`。MIT 上游来源与改动范围见 `NOTICE`。
